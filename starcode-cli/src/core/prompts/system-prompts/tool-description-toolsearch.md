Search for available tools matching a query.

**Use for**: discovering tools, finding tool capabilities.
**NOT for**: searching code (use `grep`), searching files (use `glob`).

**Params**: `query` (search term)

**Rules**:
- Returns matching tool names and descriptions
- Use when unsure which tool exists for a task
