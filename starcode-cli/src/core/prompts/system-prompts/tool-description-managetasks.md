Task tracking for multi-step work. Create, update, complete tasks.

**Use for**: complex tasks with 3+ steps, tracking progress, breaking down work.
**NOT for**: simple 1-2 step operations, non-sequential work.

**Rules**:
- Create tasks before starting multi-step work
- Mark completed immediately after finishing each step
- Use `task_get`/`task_list`/`task_update`/`task_output` for granular control
