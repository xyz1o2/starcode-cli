Check `gh` auth status, list GitHub Apps, get setup guidance.

**Use for**: verifying `gh` authentication, app management.
**NOT for**: Issue/PR operations (use dedicated tools).

**Actions**: `install` | `list` | `status`

**Rules**:
- `status`: check current auth state
- `list`: show installed apps
- `install`: provide setup instructions
