Enter plan mode for complex tasks requiring structured thinking.

**Use for**: complex multi-step tasks, architecture decisions, when user asks to "plan".
**NOT for**: simple tasks, direct execution requests.

**Rules**:
- Analyzes task complexity and creates structured plan
- Presents plan for user approval before execution
- Use when approach is unclear or task is large
