Get or set StarCode configuration items.

**Use for**: adjusting theme, model, permission mode, and other runtime settings.
**NOT for**: project-specific configuration files (use `edit`).

**Rules**:
- Read current settings before changing them
- Prefer targeted set operations over broad rewrites
