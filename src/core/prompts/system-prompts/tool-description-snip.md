CRUD for code snippets. Stored in `.star/snips.json`.

**Use for**: reusable code patterns, frequently used snippets.
**NOT for**: one-time code, file-based storage sufficient.

**Actions**: `save` | `get` | `list` | `delete`

**Params**: `name`, `content` (for save), `language` (optional)
