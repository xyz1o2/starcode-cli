AI-assisted edit that understands code context for complex modifications.

**Use for**: complex refactors needing semantic understanding, style changes.
**NOT for**: simple string replacements (use `replace`).

**Rules**:
- Provides more context-aware editing than basic replace
- Useful for structural changes
- Higher latency than `replace` — use when needed
