Store information persistently across sessions.

**Use for**: user preferences, project conventions, learned patterns.
**NOT for**: temporary notes, task-specific data.

**Params**: `key`, `value`, `category` (optional)

**Rules**:
- Persists in `.star/memory/`
- Use for cross-session knowledge
- Organize with categories for retrieval
