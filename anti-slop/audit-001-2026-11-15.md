# StarCode TUI 截图问题审查（2026-11-15）

范围：用户提供的七张截图、当前源码、`.code/claude-code-main` 的局部 UI 参考。仅静态核对，不含真实 TUI/模型复现；参考副本不是行为权威。优先级 P1 = 误导决策或损坏状态，P2 = 体验断层，P3 = 待复现。

1. **P1，已确认：失败子代理显示等待首个工具调用。** `src/agent/subagent/runner.rs:750-799` 生成失败结果，但终态 UI payload 未携带错误正文；`src/ui/components/chat_history.rs:474-479` 对所有空详情无条件显示 `Waiting for the first tool call…`。启动后立即失败可出现红叉、0 次工具、接近 0ms 与等待文案并存。用户看不到失败原因，违反 UI 错误态应提供原因和下一步（R-27）。建议终态携带失败摘要，在历史卡片/详情显示明确错误，空等待文案只适用于 Running/Background。
2. **P1，已确认代码缺口，截图关联待复现：插入工具结果时不迁移代理条目索引。** `src/ui/services/stream/tool_result.rs:241-246` 在工具调用后插入结果；`src/ui/services/stream/index_shift.rs:7-95` 迁移其它索引，却漏掉 `active_agent_tasks[*].entry_idx`；`src/ui/services/stream/agent_task.rs:52-63` 只检查旧索引仍在界内，不检查条目是否属于该 task。若插入位置在任务条目前方，之后更新可落错条目、旧卡片不刷新。建议迁移索引并校验 task/group 归属，添加纯状态回放测试。
3. **P1，已确认：SendMessage 权限卡不展示要发给谁、发什么。** `src/agent/tool_executor.rs:165-170` 的确认摘要只抽取 `command` / `file_path`；`src/core/tools/cross_agent.rs:59-67,191-219` 的 `target_agent`、`summary`、`message` 因此不在卡片摘要里；`src/ui/components/confirmation_dialog.rs:436-450` 对 Generic prompt 只展示前 60 列，截图出现 `No allow ...` 截断。用户无法在批准前核对外发内容，违反交互信息完整性（R-26）。建议为消息工具展示接收方、消息摘要及可展开正文，较长提示按宽度折行；不要通过直接自动放行掩盖这一缺陷。
4. **P2，已确认：任务详情空态不区分思考/等待/失败。** `src/agent/subagent/runner.rs:240-279` 的进度追踪侧重完整文本和工具事件；`src/ui/components/chat_history.rs:421-479` 不显示最近工具信息和 tokens，只在没有子条目时显示等待首工具。即使任务仍在思考或网络等待，也像完全没开始；失败情形见 1（R-27）。建议基于真实状态显示 `正在等待模型响应` / `等待首个工具调用` / `执行失败`，并展示最后一次已知进度。
5. **P2，已确认交互限制：终态详情自动退出且无法从历史重新打开。** `src/ui/services/stream/agent_task.rs:84-94` 收终态自动回主会话，`src/ui/state/store/mod.rs:1395-1425` 历史入口只允许打开运行中任务。自动收起符合此前用户需求，但失败原因和最终结果必须在历史卡片可见；是否允许重开已完成详情属于后续交互选择（R-26）。
6. **P2，条件性分组错误：时间窗可能跨回合混组。** `src/ui/services/stream/agent_task.rs:135-166` 在整段聊天历史中找三秒内最近 Agent 条目，没有同一调用批次或消息 ID 约束；相邻回合任务可能被归成同组。建议按调用批次/父回合归属，而非靠时间窗口。截图的 `Running 2 of 2` 与底部多行不必然矛盾：`src/ui/components/agent_group_render.rs:25-55` 只数该组成员，`src/ui/state/store/mod.rs:1351-1374` 底部只列仍在运行的异步任务。
7. **P2，作用域不明确：子代理详情与主任务面板同屏。** 当前 Todo/Task 面板按主会话状态更新，详情只替换聊天区，不能把面板当成当前所选子代理的任务。建议明确标记主任务的作用域；无需假定子代理 todo 未运行（R-31，信息层级应有明确含义）。
8. **P3，待复现：截图中重复工具行。** `src/ui/services/stream/mod.rs:917-937` 按 tool-call ID 跳过已有工具调用，但同一可视文案可能属于不同 ID，或一次结果插入与历史回显。需以事件轨迹中的 ID、调用次数和渲染条目比对，不能仅凭相同 `search(...)` 行断言重复执行。
9. **P3，待复现：思考正文铺满屏幕与截图七蓝色竖条。** `src/ui/state/store/mod.rs:1216-1237` 默认收起思考，手动展开和 transcript 模式会摊开；`src/ui/components/message_render.rs:385-423` 在流式正文末追加蓝色 `▌`。截图七仅有局部画面，尚无法判定是多个未终结的空消息、重绘残影还是正常光标。需记录当时的条目类型、`is_streaming` 和模式状态，再做 snapshot/终端复现。
